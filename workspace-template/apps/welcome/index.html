the mental model

workspace this directory tree, served live and git-versioned — the page you're looking at is the filesystem
component any directory with an index.html (a card / view) and/or a backend; its path is its identity — mv renames it, cp -r forks it
backend an optional live process (go / node / python) next to the view; rebuilt and swapped every time you save
scope a subtree that acts as one app: owns its resources (kv, sqlite, files, pub/sub, cron) and its trust boundary
shell the layout around this card — top bar, sidebar, canvas — is itself just the shell/ component, editable like anything else
terminal a real shell in a per-tile dev sandbox (the >_ title-bar button) — it acts as the tile, never as you; admin work stays in the browser or host-side bx
what that adds up to

You can build and reshape apps from the inside, while they run: make a directory and it appears in the sidebar; save a file and the card reloads; give an app a backend and wire apps to each other through granted APIs. No deploy step, no build step — see /docs/ or AGENTS.md to start.
