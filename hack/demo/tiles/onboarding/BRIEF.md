# Onboarding tracker — brief for Merrow

We track customer onboarding in a spreadsheet that nobody opens. I'd like a
small tile instead:

- one card per customer we're onboarding (pilots, new depots, driver-app
  rollouts), with how far along they are and when they go live;
- each customer's checklist, so anyone on the team can tick a step;
- pull plan, fleet size and health from the CRM so we don't copy them by hand;
- flag steps that are late.

Keep it simple: no backend unless you need one. — Priya
