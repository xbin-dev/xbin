# native/ — the xbin app (iOS first)

The mobile client of an xbin workspace: several workspaces, device login with
the Secure Enclave, a native terminal and ACP agent, every tile as a polished
WebView of its web frontend, and native UIs for tiles that ship a `native.js`.
Nothing is built yet — the design is **plans/native.md** (with
plans/tile-asset-auth.md and plans/agent-template-native.md), and the dev loop
for working here without a Mac is **AGENTS.md** in this directory.
